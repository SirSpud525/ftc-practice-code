This repo contains useful practice code functions for FTC, and can be used alongside https://github.com/SirSpud525/ftc-teacher-cloneable. Unit 1 takes the shape of a text file for each the problems and key, and can be completed in IntelIJ Idea or an online IDE. The PracticeCode folder can be opened in Android Studio as a project, and contains problems for Units 2-4. Another readme txt file inside of this folder details what some symbols mean, be sure to view this. It is also recommended to version control the project, best done by forking it before cloning it.

For contributors:
The SDK may need to be brought up to date in future seasons, if the code is run on the robot or if the SDK adds new tools. This can be accomplished by cloning the project, adding a remote which links to the FTCRobotController SDK repo, then pulling and merging changes from that remote into the current project. Due to the structure, this might be a little bit more difficult, and you might need to initialize another repo inside the PracticeCode folder, update the SDK, then delete the .git folder there and push the entire project back here from cmd line git.
